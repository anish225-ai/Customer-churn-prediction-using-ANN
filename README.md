# Customer Churn Prediction Using ANN
## Project overview
This project predicts customer churn using an Artificial Neural Network (ANN).
The model analyzes customer information and predicts whether a customer is likely to leave the compy or stay.

## Technologise Used
Python , Pandas , Numpy , Tensorflow/keras, scikit-learn, Matplotlib

# Features 
Data preprocessing
Feature encoding
ANN modle building
Model training and testing
Customer churn prediction

# data set
The dataset contains customer information such as:
Credit Score
Geography
Gender
Age
Balance
Estimated Salary
Tenure
## project workflow
Import dataset
Data preprocessin
Train-test split
Feature scalilng
Build ANN model
Train the Model
Evaluate accuracy
predict customer churn
